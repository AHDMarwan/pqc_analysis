# Spectral accessibility of quantum tangents — reproduction and falsification suite

This directory is a clean-room, NumPy/SciPy implementation of the numerical program behind the manuscript **“Spectral Geometry of Accessible Quantum Tangents: Beyond Isotropic Readout-Rank Laws.”** The three author-supplied legacy notebooks were used as provenance/audit inputs; their exact SHA-256 hashes are recorded in `provenance/LEGACY_NOTEBOOKS.md`. The production experiments use the tested package in `src/qaccess/` rather than hidden notebook state.

The objective is **not to make the manuscript look right**. It is to make wrong claims easy to detect. Scientific outcomes never cause CI to pass or fail. CI fails only for numerical/programming invariants or for an explicitly requested exact-reproduction check against the manuscript's already reported table.

## Independent reproduction status

A fresh local run of the corrected confirmatory schedule reproduced all six Table-I mean rows to the manuscript's printed precision. The intended schedule is 6 instances for each of the three generic families and 12 instances for the U(1) family at every `n`, with 48 tangent directions per fixed circuit.

Compact verified outputs are committed under `reference/verified_reproduction_20260809/`. Raw reruns are regenerated by GitHub Actions rather than treated as immutable evidence.

## What is tested

The suite separates exact mathematical/numerical identities from empirical VQC claims.

- **Reproduction:** `n = 6,8,10`, `d = 6n`, the four manuscript circuit families, 90 independent fixed circuits, 4320 analytic tangent directions.
- **Architecture diversity:** five nonconserving families plus two U(1)-conserving topologies.
- **Finite-size sweep:** up to `n = 12` in the main expanded profile.
- **Depth sweep:** `d/n = 0.5,1,2,4,6,8`.
- **Spectral test:** large tangent ensembles (`M=1024`) at tractable sizes, empirical covariance spectra, Ky-Fan sums, random-subspace controls, and split-sample Ky-Fan recovery.
- **Robustness:** three parameter initialization laws, computational/X/local-Haar product measurement bases, and independent bit-flip readout noise.
- **Tangent convergence:** nested `M=32,64,128,256` prefixes using the same fixed circuit and directions.
- **Theory controls:** Fisher contraction, trace-overlap identity, exact isotropic Beta-law moments/distributions, and relative-orientation rank laws for deliberately anisotropic tangent ensembles.

The complete falsification logic is in [`docs/EXPERIMENT_PLAN.md`](docs/EXPERIMENT_PLAN.md).

## Run locally

```bash
cd spectral_accessibility
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-lock.txt
python -m pip install -e . --no-deps
pytest
qaccess controls --output results/controls
qaccess plan --profile reproduce
```

A single shard can be run explicitly with `qaccess run-task ...`; the GitHub workflow constructs those commands automatically from the frozen profile.

## Run on GitHub Actions

Open **Actions → Spectral accessibility experiments → Run workflow**, choose one profile, and run it. The workflow:

1. generates a deterministic experiment matrix;
2. runs independent fixed-circuit shards on GitHub-hosted runners;
3. uploads every raw shard as an artifact;
4. aggregates only after all shards complete;
5. runs theory controls and produces CSV/PDF/PNG reports plus SHA-256 manifests;
6. for `reproduce` only, checks the already-published rounded Table-I means.

The scientific outcomes themselves are never used as a green/red gate. A surprising or negative result is a result, not a CI failure.

## Reproducibility rules

- Master seed is frozen to `20260809` and all derived RNG streams are recorded in `seed_ledger.csv`.
- No outcome-dependent resampling, seed selection, family deletion, or optional stopping.
- The fixed circuit, not the tangent direction, is the independent experimental unit for confidence intervals.
- All requested circuit instances are retained unless a hard numerical invariant fails; such a failure aborts and is reported.
- `d_eff = 1 / \hat\Pi` is explicitly treated as a finite-sample diagnostic because the pairwise purity estimator is unbiased but its inverse is not.
- Full empirical spectra are not inferred from `M=48`; the spectral profile uses much larger `M` and reports split-sample recovery to reduce in-sample eigenspace optimism.

See [`docs/AUDIT_NOTES.md`](docs/AUDIT_NOTES.md) for discrepancies found while reconstructing the original notebooks.
