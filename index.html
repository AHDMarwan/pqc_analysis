PQC Analysis

A Python toolkit for studying parameterized quantum circuits. It provides geometric, trainability, resource, benchmarking, and experimental topological analyses that can be used alongside existing quantum programming frameworks.

Version 0.2Python 3.11+MIT LicensePennyLane supportOptional Qiskit and TDA integrations

Scope

The package is intended for measuring and comparing properties of variational quantum circuits. It is not a circuit framework or simulator.

Quantum geometry

Fubini–Study metric tensors, spectra, rank, conditioning, effective dimension, and local parameter redundancy.

Trainability

Gradient statistics, per-parameter and layer-wise profiles, near-zero fractions, and scaling across system sizes.

Redundancy analysis

Metric null-space analysis and conservative ranking of parameters associated with locally redundant directions.

Resource estimates

Approximate circuit-evaluation and shot counts for parameter-shift, SPSA, and finite-difference protocols.

Benchmarking

Evaluation of multiple circuit architectures under common seeds and settings, with flat records for later analysis.

Framework adapters

PennyLane is supported directly; Qiskit is available as an optional integration.

Basic use

import pqc_analysis as pqa

report = pqa.analyze(
    circuit,
    n_qubits=6,
    n_params=24,
    samples=100,
)

print(report.summary())

Individual modules can be used directly when only one type of analysis is needed.

Experimental topology module

The experimental module samples the state space generated by a PQC and applies persistent homology to a pairwise distance matrix. For pure states, the current implementation uses the pure-state form of the Bures distance computed from state overlaps.

Current experiments compare persistence summaries with geometric and trainability quantities across ansatz families, qubit counts, depths, and local or global observables.

This part of the package is experimental. Correlations with trainability metrics are treated as exploratory results and are not presented as established predictors.

Benchmark experiments

The repository includes a manual GitHub Actions workflow for pilot and full topology/geometry/trainability studies. Results are exported as CSV and JSON artifacts.

python scripts/run_topology_matrix.py \
  --profile pilot \
  --output artifacts/topology_matrix

Installation

git clone https://github.com/AHDMarwan/pqc_analysis.git
cd pqc_analysis
pip install -e .

Optional integrations:

pip install -e ".[qiskit]"
pip install -e ".[tda]"
pip install -e ".[all]"

Project status

The core geometry, gradient, benchmarking, and resource modules have automated tests. The topology module is maintained separately as an experimental research component.

Source code, tests, examples, research notes, and citation metadata are available in the repository.
