Core capabilities

Diagnostics built for QML research, not just circuit execution.

The package focuses on the failure modes researchers repeatedly need to measure, compare and report.

G

Quantum geometry

Fubini–Study metric tensors, spectra, rank, conditioning, effective dimension and redundant parameter directions.

∇

Trainability profiles

Global, per-parameter and layer-wise gradient statistics with near-zero fractions and weak-parameter ranking.

BP

Barren-plateau scaling

Fit gradient-variance scaling across system sizes instead of labelling one small gradient as a barren plateau.

P

Geometry-aware pruning

Use the local metric null space to rank conservative pruning candidates and validate redundancy across samples.

R

Resource accounting

Estimate circuit evaluations and shot budgets for parameter-shift, SPSA and finite-difference training protocols.

B

Reproducible benchmarks

Compare architectures across common seeds and protocols with flat, CSV-friendly geometry, trainability and cost records.

One analysis layer

Keep your framework. Add diagnostics.

PQC Analysis is designed to sit above quantum programming frameworks rather than replace them. The statistical core stays backend-independent while adapters connect PennyLane and Qiskit workflows.

quickstart.py
import pennylane as qml
import pqc_analysis as pqa

def circuit(theta):
    qml.RY(theta[0], wires=0)
    qml.RY(theta[1], wires=1)
    qml.CNOT(wires=[0, 1])
    return qml.state()

report = pqa.analyze(
    circuit,
    n_qubits=2,
    n_params=2,
    samples=100,
)

print(report.summary())
Research questions

Built around questions that matter in variational quantum algorithms.

The project intentionally distinguishes measured evidence from heuristic diagnosis and avoids turning numerical convenience into scientific claims.

Is the ansatz over-parameterized?

Inspect Fubini–Study rank, spectrum and null-space participation to identify locally redundant coordinates.

geometry

Where does training become weak?

Separate globally small gradients from localized weak layers or specific parameter subsets.

trainability

Is suppression scaling exponentially?

Run multi-size gradient-variance scans and report slope and fit quality instead of relying on arbitrary thresholds.

barren plateaus

Which architecture is cheaper under equal budgets?

Benchmark geometry and trainability alongside circuit-evaluation and shot costs under a shared protocol.

Conservative by design

Pruning proposals do not mutate circuits automatically. Candidate removal changes the hypothesis class and should be followed by geometry, trainability and task-level re-evaluation.

Transparent resource assumptions

Hardware-style evaluation counts are reported where meaningful. Adjoint and backpropagation are not assigned fictitious universal shot counts.
